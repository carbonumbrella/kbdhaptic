kbdhaptic - виброотклик экранной клавиатуры для MSI Claw (Windows 11)
=====================================================================

Что делает
----------
Даёт короткий виброотклик контроллера на каждое нажатие клавиши экранной
(сенсорной) клавиатуры Windows. Вне клавиатуры (рабочий стол, игры, прокрутка)
вибрации нет. Работает в фоне, иконка в трее.

Поддерживается раскладка сенсорной клавиатуры "Игровая приставка": виброотклик
срабатывает и при наборе текста геймпадом.

Умеет поворачивать экран по датчику ориентации (автоповорот), когда штатный
автоповорот Windows на хендхелде не работает. Включается отдельно, см. ниже.

Как работает
------------
Ловит нажатия клавиш низкоуровневым хуком и, пока сенсорная клавиатура открыта,
бьёт импульс по мотору геймпада через XInput. Прав администратора не требует.

Установка
---------
Запусти Install.cmd. Он скопирует программу в %LOCALAPPDATA%\kbdhaptic,
поставит автозапуск при входе в систему, создаст ярлык на рабочем столе и
запустит её. В конце предложит включить автоповорот (см. ниже).

Автоповорот экрана
------------------
Чтобы заработал поворот, Windows должен считать устройство планшетом. Это
включает файл Enable-AutoRotate.reg (запись в реестр, нужны права администратора,
затем перезагрузка или перезаход). Установщик предлагает сделать это сам. Пока
фича не включена, галка "Автоповорот экрана" в настройках заблокирована.
Сам поворот выполняет kbdhaptic; тумблер "Автоповорот" в быстрых настройках
Windows работает как замок (вкл/выкл).

Удаление
--------
Запусти Uninstall.cmd (удалит программу, автозапуск и ярлык).

Настройка
---------
Иконка в трее (синяя клавиатура), двойной клик открывает окно:
  - Малый мотор (R):   высокочастотный мотор, резкий щелчок (основной отклик).
  - Большой мотор (L): низкочастотный мотор, глубокий гул.
  - Длина импульса:    1..40 мс.
  - Тест:              пробный импульс текущими настройками.
  - Поле ввода:        тапни и печатай, чтобы почувствовать отклик вживую.
  - Кнопки геймпада в проводнике: когда активно окно проводника, геймпад
                       управляет им (вне проводника и в играх не срабатывает),
                       каждое действие с виброоткликом:
                         A - открыть (Enter)
                         Y - уровень вверх (Alt+Вверх)
                         B - назад (Alt+Влево)
                         X - контекстное меню
                       Галка в настройках.
  - Автоповорот экрана: группа "Экран" в настройках (заблокирована, пока не
                       включена поддержка в Windows, см. выше).
Меню трея: Включено (вкл/выкл), Настройки, Выход.
Все настройки сохраняются в kbdhaptic.ini рядом с программой.

Файлы
-----
kbdhaptic.exe        - программа (один файл, без зависимостей кроме .NET
                       Framework 4.x, он есть в Windows по умолчанию).
kbdhaptic.ini        - настройки (создаётся при первом запуске).
Enable-AutoRotate.reg - включение поддержки автоповорота в Windows (опционально).
